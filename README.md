# Video Mocap Companion

Interactive companion guide to the 4E Video Mocap Blender add-on (video or webcam in, clean
retargeted animation out). Open `index.html` in any browser, or visit the GitHub Pages site.

The page is a single self-contained file. Its sample data is generated from the project with
`scripts/make_guide_data.py` and `scripts/build_guide.py`.
